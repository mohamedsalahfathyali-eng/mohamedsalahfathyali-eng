# Pix AI — مساعد ذكاء اصطناعي بالمصري

**جرّبه مجانًا:** [pix-ai-production.up.railway.app](https://pix-ai-production.up.railway.app)

اسأل بالمصري، و**Pix** يخلّص لك الشغل:

- يكتب ويترجم ويلخّص (إيميلات، عقود، تقارير، بوستات)
- يعمل شيتات **إكسيل** بمعادلات شغالة، وملفات **Word** و **PDF** منسقة
- يعمل برامج ومواقع وإضافات كروم وعروض باوربوينت
- يقرا ملفاتك وصورك (PDF و Word وإكسيل)
- يدوّر في الأخبار ويجيب لك المصادر
- عربي وإنجليزي، ومن غير كارت

## English

**Pix AI** is a free AI assistant that understands Egyptian Arabic. It writes and translates, builds Excel sheets with real formulas, exports Word and PDF documents, writes code, reads your files and images, and searches the news with sources.

👉 **Try it:** https://pix-ai-production.up.railway.app
